# 氣律實驗室

[简体中文](./README.md) · [English](./README.en.md)

## 專案簡介

氣律實驗室是一款面向熱學與分子運動實驗的 Windows 桌面軟體，包含標準硬球分子模擬、理想氣體關係驗證，以及絕熱膨脹法和活塞振動法兩套空氣比熱容比實驗。

本倉庫是公開發佈倉庫，只提供安裝程式、自動更新資產和多語言版本說明；應用程式原始碼在獨立的受控倉庫 [hard-sphere-lab-1](https://github.com/yanshi-qibixunchang/hard-sphere-lab-1) 中維護，存取原始碼倉庫可能需要相應權限。

## 下載與安裝

目前最新穩定版為 [`v6.3.1`](https://github.com/yanshi-qibixunchang/gas-laws-lab-release/releases/tag/v6.3.1)。請從 Releases 頁面下載 `heat-capacity-lab-setup-6.3.1.exe`，確認來源為本倉庫後執行安裝。

從 6.3.0 升級時不需要解除安裝舊版本。6.3.1 保持相同的應用程式 ID、安裝身分、更新倉庫和 `C:\Users\<使用者名稱>\AppData\Roaming\hard-sphere-lab` 使用者資料目錄；請勿在升級前清空該目錄。可靠的自由實驗計畫、已儲存曲線、框選、草稿、作答、擬合、計算和歷史模型快照會繼續還原，不會被重新解釋。

已撤回的 5.1.2 實驗版資料不在相容承諾內。如果舊資料導致程式無法啟動，請先備份使用者資料目錄，再依 Release 說明處理；不要直接刪除唯一的資料副本。

## 自動更新

開啟應用程式內「說明」→「關於」，點擊「檢查更新」。穩定更新必須在同一個 GitHub Release 中同時包含以下三個同版本檔案：

- `heat-capacity-lab-setup-6.3.1.exe`
- `heat-capacity-lab-setup-6.3.1.exe.blockmap`
- `latest.yml`

如果自動更新失敗，可手動下載最新安裝程式並覆蓋安裝。除非 Release 明確說明存在不相容，否則不需要先解除安裝。

## 實驗模組

### 空氣比熱容比（絕熱膨脹法）

支援演示、引導和自由模式，涵蓋調零、打氣、等待、快速放氣、恢復、U₀/U₁/U₂ 記錄、多組實驗、計算、評分、過程回顧和報告匯出。

### 空氣比熱容比（活塞振動法）

6.3.1 在 6.3.0 的連續熱—感測—虛擬手採集鏈上完成資料品質和顯示節奏收口：

- 整條曲線不足半個可信主週期時只自動重做目前 Run，並保留不可用記錄、採集參數和物理快照；曲線可用但框選過窄時只要求重新框選。
- 自由模式的 `t₁、t₂、T` 和最終 `A、γ、相對誤差` 均改為統一校驗；校驗前可以返回修改，格式錯誤的草稿不會被記作正式錯誤嘗試。
- 新實驗加入依種子固定的尾段局部摺疊與峰谷肩部削弱，使後段框選品質會自然影響擬合；同一曲線儲存和重新啟動後逐點一致，底層熱—力學軌跡和 `1000 Hz` 時間網格不變。
- 新實驗的按壓與自由振動統一使用版本化 `1.1 N·s/m` 等效損耗；舊存檔繼續依已儲存的 `0.434 N·s/m` 或其他受支援快照還原。
- 雙手放手時間差會產生短時衰減的側向接觸損耗，但不會在單手先放時錯誤地讓平臺立即上移，也不會加入永久摩擦。
- 曲線增加 `0.300 s` 呈現延遲，前 `0.400 s` 物理時間以 `0.55` 倍節奏顯示；該慢放不改變取樣點、時間戳、週期或計算結果。
- 修正未越過觸發線後再次按壓時監測點不更新、音效偶發失效的問題，並修正統一校驗按鈕文字溢出。

### 標準模擬與理想氣體

標準模擬提供硬球分子運動、即時取樣和結果圖表。理想氣體模組支援 `P-T`、`P-V` 和 `P-N` 關係掃描、擬合與驗證。

## 常見問題

**升級後會遺失舊實驗嗎？**  
正常的 6.3.0 → 6.3.1 覆蓋升級會沿用原使用者資料目錄，並保留可靠的自由模式資料和歷史模型快照。仍建議在重要課程或實驗前備份該目錄。

**為什麼即時資料區只顯示「電源關閉」？**  
這是活塞振動法的正常關機狀態。請先按下 3D 儀器上的電源開關。

**自動更新失敗怎麼辦？**  
從本倉庫 Releases 手動下載 6.3.1 安裝程式並覆蓋安裝；保留使用者資料目錄。

**為什麼 Windows 可能顯示安全警告？**  
Windows 可能對來自網際網路且尚未建立足夠信譽的安裝程式顯示提示。請先核對下載位址和 Release 中的檔名。
