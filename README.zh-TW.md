# 氣律實驗室

[简体中文](./README.md) · [English](./README.en.md)

## 專案簡介

氣律實驗室是一款面向熱學與分子運動實驗的 Windows 桌面軟體，包含標準硬球分子模擬、理想氣體關係驗證，以及絕熱膨脹法和活塞振動法兩套空氣比熱容比實驗。

本倉庫是公開發佈倉庫，提供 Windows 安裝程式、自動更新資產和多語言版本說明。經匿名處理的版本原始碼與逐次提交歷史發佈在 [gas-laws-lab-history](https://github.com/yanshi-qibixunchang/gas-laws-lab-history)；研究報告工作材料不屬於公開原始碼鏡像。

## 下載與安裝

目前最新穩定版為 [`v6.4.0`](https://github.com/yanshi-qibixunchang/gas-laws-lab-release/releases/tag/v6.4.0)。請從 Releases 頁面下載 `heat-capacity-lab-setup-6.4.0.exe`，確認來源為本倉庫後執行安裝。

從 6.3.1 升級不需要解除安裝舊版本。6.4.0 保持相同的應用程式 ID、安裝身分、更新倉庫和 `C:\Users\<使用者名稱>\AppData\Roaming\hard-sphere-lab` 使用者資料目錄。可靠的自由實驗計畫、已儲存曲線、參數快照、框選、作答、擬合、計算和過程證據會繼續還原，舊實驗不會依新參數重新生成。

已撤回的 5.1.2 實驗版資料不在相容承諾內。若舊資料導致程式無法啟動，請先備份使用者資料目錄，再依 Release 說明處理。

## 自動更新

開啟應用程式內「說明」→「關於」，點擊「檢查更新」。穩定更新必須在同一個 GitHub Release 中同時包含：

- `heat-capacity-lab-setup-6.4.0.exe`
- `heat-capacity-lab-setup-6.4.0.exe.blockmap`
- `latest.yml`

若自動更新失敗，可手動下載最新安裝程式並覆蓋安裝。除非 Release 明確說明不相容，否則不需要先解除安裝。

## 實驗模組

### 空氣比熱容比（絕熱膨脹法）

支援演示、引導和自由模式，涵蓋調零、打氣、等待、快速放氣、恢復、U₀/U₁/U₂ 記錄、多組實驗、計算、評分、過程回顧和報告匯出。

### 空氣比熱容比（活塞振動法）

6.4.0 在 6.3.1 已完成的連續熱—感測—虛擬手採集模型上補齊課程結果閉環：

- 自由模式新增逐次過程回顧與評分。切換實驗次數會同步更新儀器操作時間軸、正式曲線、週期選區、關鍵證據和可展開評分明細。
- 普通操作、儲存曲線等重點節點沿用另一熱容量比實驗的顏色、節點和懸浮資訊規則；再次按壓、重設、觸底、軟管、電源和雙手放手時間差只在實際發生時記錄。
- 完成活塞振動法 PDF 實驗報告，精簡呈現實驗檔案、逐次記錄、週期、擬合、最終計算、過程證據和評分，不另外增加原理或公式章節。
- 自由模式右側參數欄開放環境壓力、環境溫度、取樣率、下降觸發線和按鍵視覺化；經風險確認後可編輯已建模的進階參數，首條正式曲線儲存後整套設定隨實驗檔案固定。
- 下降觸發線範圍會隨環境壓力依相同比例縮放，標準環境仍維持已審核的 `96–130 kPa` 視窗，並受感測器量程限制。
- 過程回顧接入後，即時採集仍可暫停、儲存和繼續；監測點、監測線及未觸發後的再次按壓保持可用。

### 標準模擬與理想氣體

標準模擬提供硬球分子運動、即時取樣和結果圖表。理想氣體模組支援 `P-T`、`P-V` 和 `P-N` 關係掃描、擬合與驗證。

## 常見問題

**升級後會遺失舊實驗嗎？**  
正常的 6.3.1 → 6.4.0 覆蓋升級會沿用原使用者資料目錄，並保留可靠實驗資料和歷史模型快照。重要課程或實驗前仍建議備份。

**為什麼即時資料區只顯示「電源關閉」？**  
這是活塞振動法的正常關機狀態，請先按下 3D 儀器上的電源開關。

**自動更新失敗怎麼辦？**  
從本倉庫 Releases 手動下載 6.4.0 安裝程式並覆蓋安裝，同時保留使用者資料目錄。

**為什麼 Windows 可能顯示安全警告？**  
Windows 可能對來自網際網路且尚未累積足夠信譽的安裝程式顯示提示，請先核對倉庫網址和 Release 檔名。
