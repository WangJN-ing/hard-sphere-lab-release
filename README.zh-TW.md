# 氣律實驗室

[简体中文](./README.md) · [English](./README.en.md)

## 專案簡介

氣律實驗室是一款面向熱學與分子運動實驗的 Windows 桌面軟體，包含標準硬球分子模擬、理想氣體關係驗證，以及絕熱膨脹法和活塞振動法兩套空氣比熱容比實驗。

本倉庫是公開發佈倉庫，只提供安裝程式、自動更新資產和多語言版本說明；應用程式原始碼位於公開原始碼倉庫 [hard-sphere-lab-1](https://github.com/WangJN-ing/hard-sphere-lab-1)。

## 下載與安裝

目前最新穩定版為 [`v6.2.1`](https://github.com/WangJN-ing/hard-sphere-lab-release/releases/tag/v6.2.1)。請從 Releases 頁面下載 `heat-capacity-lab-setup-6.2.1.exe`，確認來源為本倉庫後執行安裝。

從 6.2.0 升級時不需要解除安裝舊版本。6.2.1 保持相同的應用程式 ID、安裝身分、更新倉庫和 `C:\Users\<使用者名稱>\AppData\Roaming\hard-sphere-lab` 使用者資料目錄；請勿在升級前清空該目錄。舊框選、自由實驗計畫、已儲存曲線、草稿、作答、擬合和計算資料會繼續還原。

已撤回的 5.1.2 實驗版資料不在相容承諾內。如果舊資料導致程式無法啟動，請先備份使用者資料目錄，再依 Release 說明處理；不要直接刪除唯一的資料副本。

## 自動更新

開啟應用程式內「說明」→「關於」，點擊「檢查更新」。穩定更新必須在同一個 GitHub Release 中同時包含以下三個同版本檔案：

- `heat-capacity-lab-setup-6.2.1.exe`
- `heat-capacity-lab-setup-6.2.1.exe.blockmap`
- `latest.yml`

如果自動更新失敗，可手動下載最新安裝程式並覆蓋安裝。除非 Release 明確說明存在不相容，否則不需要先解除安裝。

## 實驗模組

### 空氣比熱容比（絕熱膨脹法）

支援演示、引導和自由模式，涵蓋調零、打氣、等待、快速放氣、恢復、U₀/U₁/U₂ 記錄、多組實驗、計算、評分、過程回顧和報告匯出。

### 空氣比熱容比（活塞振動法）

6.2.0 在既有演示與引導流程上完成自由模式，並統一三種模式的儀器狀態和載入平衡模型。6.2.1 是針對採集、框選、回彈和還原流程的穩定性修補。

- 修正第一次按壓記錄剛觸發、正式曲線尚未完整時的白屏，即時曲線、暫停和儲存可以連續完成。
- 修正框選結束瞬間的資料格式崩潰，並相容舊版本儲存的大整數形式；框選方式、端點、週期規則和精度不變。
- 刪除無物理依據的固定回彈速度範圍，正常超過 `2 m/s` 的峰值不再被截斷或誤報，其他物理邊界和發散檢查繼續保留。
- 還原鬆開鎖緊螺釘後的可見輕微下沉；真實動畫執行故障會靜默回到目前穩定位置且保留資料。
- 資料處理或計算顯示錯誤只替換內容區，保留工作臺結構和實驗資料；更外層故障仍保留真實視窗控制按鈕。
- 重新啟動只清除無法繼續的按壓、手持、自由下落、回彈和短動畫，實驗計畫、曲線、草稿、框選、作答、擬合和計算繼續保留。

- 自由模式可建立 3–6 次實驗計畫，選擇系統高度或任意數量的 `10–80 mm` 整數自訂候選，並按目標高度由高到低推進。
- 每個 Run 獨立儲存 `1–1000 Hz` 取樣率、`96.0–130.0 kPa` 下降觸發閾值、原始樣本、週期選區、作答歷史和物理快照；監測圖會動態確保閾值線與曲線可見。
- 離開模式、重新整理或重新開啟檔案都會還原同一輪計畫。進度選單可重做、刪除或重設整輪，最後一次週期核驗後自動進入擬合與計算。
- 關閉計算後返回 3D 儀器與即時資料版面，歷史資料從左側「資料處理」重新開啟；左側資料入口會按演示、引導和自由模式動態顯示。
- 鬆開鎖緊螺釘後，活塞會在 `0.2 s` 內平滑單向下沉到真實載入平衡；名義高度繼續用於教學顯示，精確高度與氣體狀態在後臺生成和儲存。
- 演示、引導和自由模式繼續共用電源門控、軟管、螺釘、平臺、採集與計算邏輯，並修正步驟銜接、離開語意、旋鈕視覺行程和資料處理返回。

### 標準模擬與理想氣體

標準模擬提供硬球分子運動、即時取樣和結果圖表。理想氣體模組支援 `P-T`、`P-V` 和 `P-N` 關係掃描、擬合與驗證。

## 常見問題

**升級後會遺失舊實驗嗎？**  
正常的 6.2.0 → 6.2.1 覆蓋升級會沿用原使用者資料目錄，並保留可靠的自由模式資料。仍建議在重要課程或實驗前備份該目錄。

**為什麼即時資料區只顯示「電源關閉」？**  
這是活塞振動法的正常關機狀態。請先按下 3D 儀器上的電源開關。

**自動更新失敗怎麼辦？**  
從本倉庫 Releases 手動下載 6.2.1 安裝程式並覆蓋安裝；保留使用者資料目錄。

**為什麼 Windows 可能顯示安全警告？**  
Windows 可能對來自網際網路且尚未建立足夠信譽的安裝程式顯示提示。請先核對下載位址和 Release 中的檔名。
