# 氣律實驗室

[简体中文](./README.md) · [English](./README.en.md)

## 專案簡介

氣律實驗室是一款面向熱學與分子運動實驗的 Windows 桌面軟體，包含標準硬球分子模擬、理想氣體關係驗證，以及絕熱膨脹法和活塞振動法兩套空氣比熱容比實驗。

本倉庫是公開發佈倉庫，只提供安裝程式、自動更新資產和多語言版本說明；應用程式原始碼位於公開原始碼倉庫 [hard-sphere-lab-1](https://github.com/WangJN-ing/hard-sphere-lab-1)。

## 下載與安裝

目前最新穩定版為 [`v6.1.1`](https://github.com/WangJN-ing/hard-sphere-lab-release/releases/tag/v6.1.1)。請從 Releases 頁面下載 `heat-capacity-lab-setup-6.1.1.exe`，確認來源為本倉庫後執行安裝。

從 5.3.1 升級時通常不需要解除安裝舊版本。6.1.1 保持相同的應用程式 ID、安裝身分、更新倉庫和 `C:\Users\<使用者名稱>\AppData\Roaming\hard-sphere-lab` 使用者資料目錄；請勿在升級前清空該目錄。發佈門禁已在全新的 Windows 暫存機上通過 5.3.1 → 6.1.1 同路徑覆蓋升級、舊資料繼承、啟動和錯誤檢查；可查閱[驗證記錄](https://github.com/WangJN-ing/hard-sphere-lab-1/actions/runs/33030767722)。

已撤回的 5.1.2 實驗版資料不在相容承諾內。如果舊資料導致程式無法啟動，請先備份使用者資料目錄，再依 Release 說明處理；不要直接刪除唯一的資料副本。

## 自動更新

開啟應用程式內「說明」→「關於」，點擊「檢查更新」。穩定更新必須在同一個 GitHub Release 中同時包含以下三個同版本檔案：

- `heat-capacity-lab-setup-6.1.1.exe`
- `heat-capacity-lab-setup-6.1.1.exe.blockmap`
- `latest.yml`

如果自動更新失敗，可手動下載最新安裝程式並覆蓋安裝。除非 Release 明確說明存在不相容，否則不需要先解除安裝。

## 實驗模組

### 空氣比熱容比（絕熱膨脹法）

支援演示、引導和自由模式，涵蓋調零、打氣、等待、快速放氣、恢復、U₀/U₁/U₂ 記錄、多組實驗、計算、評分、過程回顧和報告匯出。

### 空氣比熱容比（活塞振動法）

6.1.1 新增完整演示模式、完整引導模式和常規 3D 操作；「自由」入口目前標記為暫未開放。

- 電源採用按壓式物理回饋，並把感測器與電腦採集軟體的開關狀態合併為一個儀器電源。
- 必須先開機，才能輸入取樣率與壓力、顯示曲線或記錄資料。關機時保留「即時資料」標題，內容區只顯示「電源關閉」。
- 引導模式嚴格按目前步驟推進。誤按其他控制項時只播放按壓回饋，不改變實驗狀態，並提示先完成目前步驟。
- 三輪實驗依序使用 80、70、60 mm 高度，涵蓋平臺與刻度調整、螺釘鎖緊/鬆開、軟管斷開/拖動/磁吸重連、採集、活塞釋放、停止、儲存和週期框選。
- 週期框選完成後恢復 3D + 即時資料版面，並要求關閉電源；關機後直接進入計算。
- 演示模式自動播放完整流程，並在結束時自動關機。

### 標準模擬與理想氣體

標準模擬提供硬球分子運動、即時取樣和結果圖表。理想氣體模組支援 `P-T`、`P-V` 和 `P-N` 關係掃描、擬合與驗證。

## 常見問題

**升級後會遺失舊實驗嗎？**  
正常的 5.3.1 → 6.1.1 覆蓋升級會沿用原使用者資料目錄。仍建議在重要課程或實驗前備份該目錄。

**為什麼即時資料區只顯示「電源關閉」？**  
這是活塞振動法的正常關機狀態。請先按下 3D 儀器上的電源開關。

**自動更新失敗怎麼辦？**  
從本倉庫 Releases 手動下載 6.1.1 安裝程式並覆蓋安裝；保留使用者資料目錄。

**為什麼 Windows 可能顯示安全警告？**  
Windows 可能對來自網際網路且尚未建立足夠信譽的安裝程式顯示提示。請先核對下載位址和 Release 中的檔名。
