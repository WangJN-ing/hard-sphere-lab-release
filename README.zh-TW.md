# 氣律實驗室

[简体中文](./README.md) · [English](./README.en.md)

## 專案簡介

氣律實驗室是一款面向熱學與分子運動實驗的 Windows 桌面軟體，包含標準硬球分子模擬、理想氣體關係驗證，以及絕熱膨脹法和活塞振動法兩套空氣比熱容比實驗。

本倉庫是公開發佈倉庫，只提供安裝程式、自動更新資產和多語言版本說明；應用程式原始碼位於公開原始碼倉庫 [hard-sphere-lab-1](https://github.com/WangJN-ing/hard-sphere-lab-1)。

## 下載與安裝

目前最新穩定版為 [`v6.3.0`](https://github.com/WangJN-ing/hard-sphere-lab-release/releases/tag/v6.3.0)。請從 Releases 頁面下載 `heat-capacity-lab-setup-6.3.0.exe`，確認來源為本倉庫後執行安裝。

從 6.2.1 升級時不需要解除安裝舊版本。6.3.0 保持相同的應用程式 ID、安裝身分、更新倉庫和 `C:\Users\<使用者名稱>\AppData\Roaming\hard-sphere-lab` 使用者資料目錄；請勿在升級前清空該目錄。可靠的自由實驗計畫、已儲存曲線、框選、草稿、作答、擬合和計算資料會繼續還原。

已撤回的 5.1.2 實驗版資料不在相容承諾內。如果舊資料導致程式無法啟動，請先備份使用者資料目錄，再依 Release 說明處理；不要直接刪除唯一的資料副本。

## 自動更新

開啟應用程式內「說明」→「關於」，點擊「檢查更新」。穩定更新必須在同一個 GitHub Release 中同時包含以下三個同版本檔案：

- `heat-capacity-lab-setup-6.3.0.exe`
- `heat-capacity-lab-setup-6.3.0.exe.blockmap`
- `latest.yml`

如果自動更新失敗，可手動下載最新安裝程式並覆蓋安裝。除非 Release 明確說明存在不相容，否則不需要先解除安裝。

## 實驗模組

### 空氣比熱容比（絕熱膨脹法）

支援演示、引導和自由模式，涵蓋調零、打氣、等待、快速放氣、恢復、U₀/U₁/U₂ 記錄、多組實驗、計算、評分、過程回顧和報告匯出。

### 空氣比熱容比（活塞振動法）

6.3.0 同時補充自由模式能力並修正引導體驗：

- 自由模式加入連續熱過程、壓力感測、按壓與虛擬雙手採集鏈；不同高度保留各自的平衡與回落特徵，顯示時鐘、原始樣本和處理資料共用同一時間基準。
- 電源、軟管接入與移除、鎖緊螺釘、活塞振動和觸底碰撞加入與狀態一致的音效；適用模式中的高度復位依實際落差回饋，小於 `5 mm` 的移動保持安靜。
- 引導清單、主控制鍵和操作門控統一讀取有效步驟，提醒後完成正確操作不再被舊條件拒絕。
- 採集達到 `0.500 s` 後先凍結曲線與時間，再開放暫停鍵推進教學；判定適配 `80 / 70 / 60 mm` 各自不同的真實回落量。
- 舊存檔中的內部基線步驟自動遷移且不再顯示；取樣率與觸發閾值輸入框支援 Enter 確認。
- 引導與演示旋鈕顯示清楚的順時針或逆時針箭頭，允許越過完成臨界值後的正確方向慣性動作，並以輕提示、邊界阻止兩級處理反向旋轉。
- 演示模式中的高度調節、軟管移除和軟管接入耗時縮短為原來的 `50%`。

### 標準模擬與理想氣體

標準模擬提供硬球分子運動、即時取樣和結果圖表。理想氣體模組支援 `P-T`、`P-V` 和 `P-N` 關係掃描、擬合與驗證。

## 常見問題

**升級後會遺失舊實驗嗎？**  
正常的 6.2.1 → 6.3.0 覆蓋升級會沿用原使用者資料目錄，並保留可靠的自由模式資料。仍建議在重要課程或實驗前備份該目錄。

**為什麼即時資料區只顯示「電源關閉」？**  
這是活塞振動法的正常關機狀態。請先按下 3D 儀器上的電源開關。

**自動更新失敗怎麼辦？**  
從本倉庫 Releases 手動下載 6.3.0 安裝程式並覆蓋安裝；保留使用者資料目錄。

**為什麼 Windows 可能顯示安全警告？**  
Windows 可能對來自網際網路且尚未建立足夠信譽的安裝程式顯示提示。請先核對下載位址和 Release 中的檔名。
