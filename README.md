# 气律实验室

[繁體中文](./README.zh-TW.md) · [English](./README.en.md)

## 项目简介

气律实验室是一款面向热学与分子运动实验的 Windows 桌面软件，包含标准硬球分子模拟、理想气体关系验证，以及绝热膨胀法和活塞振动法两套空气比热容比实验。

本仓库是公开发行仓库，只提供安装包、自动更新资产和多语言版本说明；应用源码在独立的受控仓库 [hard-sphere-lab-1](https://github.com/yanshi-qibixunchang/hard-sphere-lab-1) 中维护，访问源码仓库可能需要相应权限。

## 下载与安装

当前最新稳定版为 [`v6.3.1`](https://github.com/yanshi-qibixunchang/gas-laws-lab-release/releases/tag/v6.3.1)。请从 Releases 页面下载 `heat-capacity-lab-setup-6.3.1.exe`，确认来源为本仓库后运行安装。

从 6.3.0 升级时不需要卸载旧版本。6.3.1 保持相同的应用 ID、安装身份、更新仓库和 `C:\Users\<用户名>\AppData\Roaming\hard-sphere-lab` 用户资料目录；请勿在升级前清空该目录。可靠的自由实验计划、已保存曲线、框选、草稿、作答、拟合和计算数据会继续恢复，旧曲线及旧模型快照不会按新参数重新生成。

已撤回的 5.1.2 实验版数据不在兼容承诺内。如果旧数据导致程序无法启动，请先备份用户资料目录，再按 Release 说明处理；不要直接删除唯一的数据副本。

## 自动更新

打开应用内“帮助”→“关于”，点击“检查更新”。稳定更新必须在同一个 GitHub Release 中同时包含以下三个同版本文件：

- `heat-capacity-lab-setup-6.3.1.exe`
- `heat-capacity-lab-setup-6.3.1.exe.blockmap`
- `latest.yml`

如果自动更新失败，可手动下载最新安装包并覆盖安装。除非 Release 明确说明存在不兼容，否则不需要先卸载。

## 实验模块

### 空气比热容比（绝热膨胀法）

支持演示、引导和自由模式，覆盖调零、打气、等待、快速放气、恢复、U₀/U₁/U₂ 记录、多组实验、计算、评分、过程回顾和报告导出。

### 空气比热容比（活塞振动法）

6.3.1 在 6.3.0 的连续热—传感—虚拟手采集链上完成数据质量和显示节奏收口：

- 整条曲线不足半个可信主周期时只自动重做当前 Run，并保留不可用记录、采集参数和物理快照；曲线可用但框选过窄时只要求重新框选。
- 自由模式的 `t₁、t₂、T` 和最终 `A、γ、相对误差` 均改为统一校验；校验前可以回改，格式错误的草稿不会被记作正式错误尝试。
- 新实验加入按种子固定的尾段局部折叠与峰谷肩部削弱，使后段框选质量会自然影响拟合；同一曲线保存和重启后逐点一致，底层热—力学轨迹和 `1000 Hz` 时间网格不变。
- 新实验的按压与自由振动统一使用版本化 `1.1 N·s/m` 等效损耗；旧存档继续按已保存的 `0.434 N·s/m` 或其他受支持快照恢复。
- 双手松手时间差会产生短时衰减的侧向接触损耗，但不会在单手先松时错误地让平台立即上移，也不会加入永久摩擦。
- 曲线增加 `0.300 s` 呈现延迟，前 `0.400 s` 物理时间以 `0.55` 倍节奏显示；该慢放不改变采样点、时间戳、周期或计算结果。
- 修复未越过触发线后再次按压时监测点不更新、音效偶发失效的问题，并修复统一校验按钮文案溢出。

### 标准模拟与理想气体

标准模拟提供硬球分子运动、实时采样和结果图表。理想气体模块支持 `P-T`、`P-V` 和 `P-N` 关系扫描、拟合与验证。

## 常见问题

**升级后会丢失旧实验吗？**  
正常的 6.3.0 → 6.3.1 覆盖升级会沿用原用户资料目录，并保留可靠的自由模式数据和旧模型快照。仍建议在重要课程或实验前备份该目录。

**为什么实时数据区只显示“电源关闭”？**  
这是活塞振动法的正常关机状态。请先按下 3D 仪器上的电源开关。

**自动更新失败怎么办？**  
从本仓库 Releases 手动下载 6.3.1 安装包并覆盖安装；保留用户资料目录。

**为什么 Windows 可能显示安全警告？**  
Windows 可能对来自互联网且未建立足够信誉的安装包显示提示。请先核对下载地址和 Release 中的文件名。
