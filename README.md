# 气律实验室

[繁體中文](./README.zh-TW.md) · [English](./README.en.md)

## 项目简介

气律实验室是一款面向热学与分子运动实验的 Windows 桌面软件，包含标准硬球分子模拟、理想气体关系验证，以及绝热膨胀法和活塞振动法两套空气比热容比实验。

本仓库是公开发行仓库，只提供安装包、自动更新资产和多语言版本说明；应用源码位于公开源码仓库 [hard-sphere-lab-1](https://github.com/WangJN-ing/hard-sphere-lab-1)。

## 下载与安装

当前最新稳定版为 [`v6.3.0`](https://github.com/WangJN-ing/hard-sphere-lab-release/releases/tag/v6.3.0)。请从 Releases 页面下载 `heat-capacity-lab-setup-6.3.0.exe`，确认来源为本仓库后运行安装。

从 6.2.1 升级时不需要卸载旧版本。6.3.0 保持相同的应用 ID、安装身份、更新仓库和 `C:\Users\<用户名>\AppData\Roaming\hard-sphere-lab` 用户资料目录；请勿在升级前清空该目录。可靠的自由实验计划、已保存曲线、框选、草稿、作答、拟合和计算数据会继续恢复。

已撤回的 5.1.2 实验版数据不在兼容承诺内。如果旧数据导致程序无法启动，请先备份用户资料目录，再按 Release 说明处理；不要直接删除唯一的数据副本。

## 自动更新

打开应用内“帮助”→“关于”，点击“检查更新”。稳定更新必须在同一个 GitHub Release 中同时包含以下三个同版本文件：

- `heat-capacity-lab-setup-6.3.0.exe`
- `heat-capacity-lab-setup-6.3.0.exe.blockmap`
- `latest.yml`

如果自动更新失败，可手动下载最新安装包并覆盖安装。除非 Release 明确说明存在不兼容，否则不需要先卸载。

## 实验模块

### 空气比热容比（绝热膨胀法）

支持演示、引导和自由模式，覆盖调零、打气、等待、快速放气、恢复、U₀/U₁/U₂ 记录、多组实验、计算、评分、过程回顾和报告导出。

### 空气比热容比（活塞振动法）

6.3.0 同时补充自由模式能力并修复引导体验：

- 自由模式新增连续热过程、压力传感、按压与虚拟双手采集链；不同高度保留各自的平衡与回落特征，显示时钟、原始样本和处理数据共用同一时间基准。
- 电源、软管接入与移除、锁紧螺钉、活塞振动和触底碰撞增加状态一致的音效；适用模式中的高度复位按实际落差反馈，小于 `5 mm` 的移动保持安静。
- 引导清单、主控制键和操作门控统一读取有效步骤，提醒后完成正确操作不再被旧条件拒绝。
- 采集达到 `0.500 s` 后先冻结曲线与时间，再开放暂停键推进教学；判定适配 `80 / 70 / 60 mm` 各自不同的真实回落量。
- 旧存档中的内部基线步骤自动迁移且不再显示；采样率与触发阈值输入框支持回车确认。
- 引导与演示旋钮显示清晰的顺时针或逆时针箭头，允许越过完成临界值后的正确方向惯性动作，并以轻提示、边界阻止两级处理反向旋转。
- 演示模式中的高度调节、软管移除和软管接入耗时缩短为原来的 `50%`。

### 标准模拟与理想气体

标准模拟提供硬球分子运动、实时采样和结果图表。理想气体模块支持 `P-T`、`P-V` 和 `P-N` 关系扫描、拟合与验证。

## 常见问题

**升级后会丢失旧实验吗？**  
正常的 6.2.1 → 6.3.0 覆盖升级会沿用原用户资料目录，并保留可靠的自由模式数据。仍建议在重要课程或实验前备份该目录。

**为什么实时数据区只显示“电源关闭”？**  
这是活塞振动法的正常关机状态。请先按下 3D 仪器上的电源开关。

**自动更新失败怎么办？**  
从本仓库 Releases 手动下载 6.3.0 安装包并覆盖安装；保留用户资料目录。

**为什么 Windows 可能显示安全警告？**  
Windows 可能对来自互联网且未建立足够信誉的安装包显示提示。请先核对下载地址和 Release 中的文件名。
