# 气律实验室

[繁體中文](./README.zh-TW.md) · [English](./README.en.md)

## 项目简介

气律实验室是一款面向热学与分子运动实验的 Windows 桌面软件，包含标准硬球分子模拟、理想气体关系验证，以及绝热膨胀法和活塞振动法两套空气比热容比实验。

本仓库是公开发行仓库，只提供安装包、自动更新资产和多语言版本说明；应用源码位于公开源码仓库 [hard-sphere-lab-1](https://github.com/WangJN-ing/hard-sphere-lab-1)。

## 下载与安装

当前最新稳定版为 [`v6.2.1`](https://github.com/WangJN-ing/hard-sphere-lab-release/releases/tag/v6.2.1)。请从 Releases 页面下载 `heat-capacity-lab-setup-6.2.1.exe`，确认来源为本仓库后运行安装。

从 6.2.0 升级时不需要卸载旧版本。6.2.1 保持相同的应用 ID、安装身份、更新仓库和 `C:\Users\<用户名>\AppData\Roaming\hard-sphere-lab` 用户资料目录；请勿在升级前清空该目录。旧框选、自由实验计划、已保存曲线、草稿、作答、拟合和计算数据会继续恢复。

已撤回的 5.1.2 实验版数据不在兼容承诺内。如果旧数据导致程序无法启动，请先备份用户资料目录，再按 Release 说明处理；不要直接删除唯一的数据副本。

## 自动更新

打开应用内“帮助”→“关于”，点击“检查更新”。稳定更新必须在同一个 GitHub Release 中同时包含以下三个同版本文件：

- `heat-capacity-lab-setup-6.2.1.exe`
- `heat-capacity-lab-setup-6.2.1.exe.blockmap`
- `latest.yml`

如果自动更新失败，可手动下载最新安装包并覆盖安装。除非 Release 明确说明存在不兼容，否则不需要先卸载。

## 实验模块

### 空气比热容比（绝热膨胀法）

支持演示、引导和自由模式，覆盖调零、打气、等待、快速放气、恢复、U₀/U₁/U₂ 记录、多组实验、计算、评分、过程回顾和报告导出。

### 空气比热容比（活塞振动法）

6.2.0 在既有演示与引导流程上完成自由模式，并统一三种模式的仪器状态和加载平衡模型。6.2.1 是针对采集、框选、回弹和恢复流程的稳定性补丁。

- 修复第一次按压记录刚触发、正式曲线尚未完整时的白屏，实时曲线、暂停和保存可以连续完成。
- 修复框选结束瞬间的数据格式崩溃，并兼容旧版本保存的大整数形式；框选方式、端点、周期规则和精度不变。
- 删除无物理依据的固定回弹速度范围，正常超过 `2 m/s` 的峰值不再被截断或误报，其他物理边界和发散检查继续保留。
- 恢复松开锁紧螺钉后的可见轻微下沉；真实动画执行故障会静默回到当前稳定位置且保留数据。
- 数据处理或计算显示错误只替换内容区，保留工作台结构和实验数据；更外层故障仍保留真实窗口控制按钮。
- 重启只清除无法继续的按压、手持、自由下落、回弹和短动画，实验计划、曲线、草稿、框选、作答、拟合和计算继续保留。

- 自由模式可建立 3–6 次实验计划，选择系统高度或任意数量的 `10–80 mm` 整数自定义候选，并按目标高度从高到低推进。
- 每个 Run 独立保存 `1–1000 Hz` 采样率、`96.0–130.0 kPa` 下降触发阈值、原始样本、周期选区、作答历史和物理快照；监测图会动态保证阈值线与曲线可见。
- 退出模式、刷新或重新打开文件都会恢复同一轮计划。进度菜单可重做、删除或重置整轮，最后一次周期核验后自动进入拟合与计算。
- 关闭计算后返回 3D 仪器与实时数据布局，历史数据从左侧“数据处理”重新打开；左侧资料入口会按演示、引导和自由模式动态显示。
- 松开锁紧螺钉后，活塞会在 `0.2 s` 内平滑单向下沉到真实加载平衡；名义高度继续用于教学显示，精确高度与气体状态在后台生成和保存。
- 演示、引导和自由模式继续共用电源门控、软管、螺钉、平台、采集与计算逻辑，并修复了步骤衔接、退出语义、旋钮视觉行程和数据处理返回。

### 标准模拟与理想气体

标准模拟提供硬球分子运动、实时采样和结果图表。理想气体模块支持 `P-T`、`P-V` 和 `P-N` 关系扫描、拟合与验证。

## 常见问题

**升级后会丢失旧实验吗？**  
正常的 6.2.0 → 6.2.1 覆盖升级会沿用原用户资料目录，并保留可靠的自由模式数据。仍建议在重要课程或实验前备份该目录。

**为什么实时数据区只显示“电源关闭”？**  
这是活塞振动法的正常关机状态。请先按下 3D 仪器上的电源开关。

**自动更新失败怎么办？**  
从本仓库 Releases 手动下载 6.2.1 安装包并覆盖安装；保留用户资料目录。

**为什么 Windows 可能显示安全警告？**  
Windows 可能对来自互联网且未建立足够信誉的安装包显示提示。请先核对下载地址和 Release 中的文件名。
