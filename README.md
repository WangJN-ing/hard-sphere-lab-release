# 气律实验室

[繁體中文](./README.zh-TW.md) · [English](./README.en.md)

## 项目简介

气律实验室是一款面向热学与分子运动实验的 Windows 桌面软件，包含标准硬球分子模拟、理想气体关系验证，以及绝热膨胀法和活塞振动法两套空气比热容比实验。

本仓库是公开发行仓库，只提供安装包、自动更新资产和多语言版本说明；应用源码位于公开源码仓库 [hard-sphere-lab-1](https://github.com/WangJN-ing/hard-sphere-lab-1)。

## 下载与安装

当前最新稳定版为 [`v6.1.1`](https://github.com/WangJN-ing/hard-sphere-lab-release/releases/tag/v6.1.1)。请从 Releases 页面下载 `heat-capacity-lab-setup-6.1.1.exe`，确认来源为本仓库后运行安装。

从 5.3.1 升级时通常不需要卸载旧版本。6.1.1 保持相同的应用 ID、安装身份、更新仓库和 `C:\Users\<用户名>\AppData\Roaming\hard-sphere-lab` 用户资料目录；请勿在升级前清空该目录。发行门禁已在全新的 Windows 临时机上通过 5.3.1 → 6.1.1 同路径覆盖升级、旧资料继承、启动和错误检查；可查阅[验证记录](https://github.com/WangJN-ing/hard-sphere-lab-1/actions/runs/33030767722)。

已撤回的 5.1.2 实验版数据不在兼容承诺内。如果旧数据导致程序无法启动，请先备份用户资料目录，再按 Release 说明处理；不要直接删除唯一的数据副本。

## 自动更新

打开应用内“帮助”→“关于”，点击“检查更新”。稳定更新必须在同一个 GitHub Release 中同时包含以下三个同版本文件：

- `heat-capacity-lab-setup-6.1.1.exe`
- `heat-capacity-lab-setup-6.1.1.exe.blockmap`
- `latest.yml`

如果自动更新失败，可手动下载最新安装包并覆盖安装。除非 Release 明确说明存在不兼容，否则不需要先卸载。

## 实验模块

### 空气比热容比（绝热膨胀法）

支持演示、引导和自由模式，覆盖调零、打气、等待、快速放气、恢复、U₀/U₁/U₂ 记录、多组实验、计算、评分、过程回顾和报告导出。

### 空气比热容比（活塞振动法）

6.1.1 新增完整演示模式、完整引导模式和常规 3D 操作；“自由”入口当前标记为暂未开放。

- 电源采用按压式物理反馈，并把传感器与电脑采集软件的开关状态合并为一个仪器电源。
- 必须先开机，才能输入采样率与压力、显示曲线或记录数据。关机时保留“实时数据”标题，内容区只显示“电源关闭”。
- 引导模式严格按当前步骤推进。误按其他控件时只播放按压反馈，不改变实验状态，并提示先完成当前步骤。
- 三轮实验依次使用 80、70、60 mm 高度，覆盖平台与刻度调整、螺钉锁紧/松开、软管断开/拖动/磁吸重连、采集、活塞释放、停止、保存和周期框选。
- 周期框选完成后恢复 3D + 实时数据布局，并要求关闭电源；关机后直接进入计算。
- 演示模式自动播放完整流程，并在结束时自动关机。

### 标准模拟与理想气体

标准模拟提供硬球分子运动、实时采样和结果图表。理想气体模块支持 `P-T`、`P-V` 和 `P-N` 关系扫描、拟合与验证。

## 常见问题

**升级后会丢失旧实验吗？**  
正常的 5.3.1 → 6.1.1 覆盖升级会沿用原用户资料目录。仍建议在重要课程或实验前备份该目录。

**为什么实时数据区只显示“电源关闭”？**  
这是活塞振动法的正常关机状态。请先按下 3D 仪器上的电源开关。

**自动更新失败怎么办？**  
从本仓库 Releases 手动下载 6.1.1 安装包并覆盖安装；保留用户资料目录。

**为什么 Windows 可能显示安全警告？**  
Windows 可能对来自互联网且未建立足够信誉的安装包显示提示。请先核对下载地址和 Release 中的文件名。
